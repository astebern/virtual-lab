# Plan Implementasi Virtual Lab TPB

## Ringkasan

Membangun aplikasi web statis satu halaman menggunakan HTML5, CSS, dan JavaScript vanilla. Aplikasi menyediakan enam course dengan satu eksperimen interaktif per course, berjalan sepenuhnya di Chrome tanpa backend, framework, penyimpanan progres, atau dependensi eksternal.

## Mini-lab

1. Matematika: turunan dan garis singgung pada fungsi kuadrat.
2. Fisika: simulasi gerak proyektil.
3. Kimia: penyetaraan reaksi dan visualisasi partikel.
4. Berpikir Komputasional: penyusunan algoritma robot maze.
5. Literasi Data dan AI: eksperimen batas klasifikasi.
6. Sustainability: alokasi kebijakan kampus berkelanjutan.

## Ketentuan

- Menggunakan semantic HTML, canvas, form HTML5, dialog, output, dan drag-and-drop.
- Menggunakan CSS responsif bergaya pixel-game minimalis tanpa gradasi.
- Menggunakan JavaScript vanilla untuk seluruh state, perhitungan, animasi, dan manipulasi DOM.
- Menyediakan alternatif tap dan keyboard untuk interaksi drag-and-drop.
- Tidak menggunakan backend, framework, library eksternal, atau penyimpanan progres.
- Tidak menambahkan komentar di dalam kode HTML, CSS, atau JavaScript.

## Validasi

- Periksa sintaks JavaScript.
- Uji enam eksperimen, tombol reset, dialog, dan navigasi.
- Uji tampilan desktop dan mobile pada Chrome.
- Pastikan console bebas error dan tidak ada horizontal overflow.
