# Virtual Lab TPB

Media pembelajaran interaktif berbasis HTML5, CSS, dan JavaScript untuk mahasiswa TPB ITB.

## Menjalankan

1. Unduh atau clone folder proyek.
2. Buka `index.html` menggunakan Google Chrome.
3. Alternatif: jalankan `python3 -m http.server 8000`, lalu buka `http://localhost:8000`.

## Course

- MA1101 Matematika: turunan dan garis singgung.
- FI1101 Fisika: gerak proyektil.
- KI1101 Kimia: penyetaraan reaksi.
- WI1102 Berpikir Komputasional: robot maze.
- WI2002 Literasi Data dan AI: batas klasifikasi.
- WI1103 Sustainability: kebijakan kampus berkelanjutan.

## Fitur

- Semantic HTML5 dan form input modern.
- Canvas untuk grafik, animasi, dan visualisasi data.
- Native drag-and-drop dengan alternatif tap.
- Layout responsif untuk laptop dan perangkat sentuh.
- Simulasi berjalan sepenuhnya di browser tanpa backend.

## Struktur

- `index.html`: struktur aplikasi.
- `styles.css`: desain dan responsive layout.
- `app.js`: data course, simulasi, dan interaksi.
- `plan.md`: rencana implementasi.
